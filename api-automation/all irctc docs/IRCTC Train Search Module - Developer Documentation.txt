## Overview

The IRCTC Train Search Module is a WPF-based application that provides comprehensive train searching functionality with station autocomplete, real-time train data fetching, and interactive result display using WebView2.

### Key Capabilities
- Station name/code autocomplete with dropdown suggestions
- Real-time train schedule fetching from erail.in API
- Interactive HTML-based result display
- Train selection for booking workflow
- Robust error handling and retry logic

## Architecture

### Technology Stack
- *Framework*: WPF (.NET)
- *UI Rendering*: WebView2 (Microsoft.Web.WebView2.Wpf)
- *HTTP Client*: System.Net.Http.HttpClient
- *JSON Processing*: Newtonsoft.Json

The module follows a *Model-View-ViewModel (MVVM)* inspired pattern with:
- *Model*: TrainInfo, Station classes
- *View*: XAML UI with WebView2 control
- *Logic*: Event-driven handlers with async/await pattern

## Key Features

### Feature 1: Station Autocomplete

#### Implementation Flow
1. User types in FromStationTextBox or ToStationTextBox
2. TextChanged event fires → UpdateStationSuggestions()
3. Filter stations by name/code (case-insensitive, minimum 2 chars)
4. Show popup window with top 10 matches
5. User selects station → Station code populates textbox

#### Code Reference
csharp
private void UpdateStationSuggestions(string searchText, TextBox textBox)
{
    // Minimum 2 characters required
    if (string.IsNullOrWhiteSpace(searchText) || searchText.Length < 2)
        return;

    // Filter stations (case-insensitive)
    var filtered = allStations.Where(s =>
        s.name.IndexOf(searchText, StringComparison.OrdinalIgnoreCase) >= 0 ||
        s.code.IndexOf(searchText, StringComparison.OrdinalIgnoreCase) >= 0
    ).Take(10).ToList();

    if (filtered.Count > 0)
        ShowSuggestions(textBox, filtered);
}


#### Keyboard Navigation
- *Down Arrow*: Move focus to suggestion list
- *Enter*: Select highlighted station
- *Escape*: Close suggestions
- *Mouse Click*: Select station

### Feature 2: Train Data Fetching

#### API Integration with erail.in

*Endpoint*: https://erail.in/rail/getTrains.aspx

*Method*: POST

*Required Headers*:
csharp
accept: */*
accept-language: en-US,en;q=0.9
access-control-request-headers: content-type
access-control-request-method: POST
origin: https://erail.in
referer: https://erail.in/
user-agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)...


*Query Parameters*:
- Station_From: Source station code (e.g., NDLS)
- Station_To: Destination station code (e.g., BCT)
- DataSource: 0 (default)
- Language: 0 (English)
- Cache: false

#### Retry Logic
csharp
const int maxRetries = 3;
const int retryDelayMs = 1000;

for (int attempt = 1; attempt <= maxRetries; attempt++)
{
    try {
        // Make API request
        var response = await httpClient.SendAsync(request, cancellationToken);
        response.EnsureSuccessStatusCode();
        // Process response
        break;
    }
    catch (HttpRequestException) when (attempt < maxRetries) {
        await Task.Delay(retryDelayMs, cancellationToken);
        continue;
    }
}

### Feature 3: Response Parsing

The API returns pipe-delimited (~) and caret-separated (^) data format:

*Example Response*:

12301~RAJDHANI EXPRESS~16.55~08.35~15.40~1111111~1A~2A~3A~SL^
12302~DURONTO SF~18.25~09.15~14.50~0101010~2A~3A~SL^


#### Parsing Strategy
1. Split by ^ to get individual train records
2. Split each record by ~ to get fields
3. Use regex patterns to identify:
   - Train number: \d{4,5} (4-5 digits)
   - Times: \d{1,2}[:.]\d{2} (HH:MM format)
   - Duration: \d{1,2}\.\d{2} (decimal hours)
   - Runs on: [01]{7} (7-bit binary pattern for days)
   - Classes: 1A|2A|3A|SL|2S|CC|FC|EC|3E

#### Code Example
csharp
private TrainInfo? ParseSingleTrainRecord(string record)
{
    var fields = record.Split('~');
    var train = new TrainInfo();

    // Find train number (regex: 4-5 digits)
    for (int i = 0; i < Math.Min(fields.Length, 5); i++)
    {
        if (Regex.IsMatch(fields[i], @"^\d{4,5}$"))
        {
            train.TrainNumber = fields[i];
            train.TrainName = CleanTrainName(fields[i + 1]);
            break;
        }
    }

    // Extract times
    var times = fields.Where(f => Regex.IsMatch(f, @"^\d{1,2}[:.]\d{2}$"))
                     .Select(t => t.Replace('.', ':'))
                     .ToList();
    
    train.DepartureTime = times.FirstOrDefault();
    train.ArrivalTime = times.Skip(1).FirstOrDefault();

    return train;
}

## Implementation Guide

### Step 1: Initialize WebView2
csharp
private async Task InitializeWebViewAsync()
{
    await webView.EnsureCoreWebView2Async();
    
    // Configure settings
    webView.CoreWebView2.Settings.IsGeneralAutofillEnabled = false;
    webView.CoreWebView2.Settings.AreDevToolsEnabled = false;
    webView.CoreWebView2.Settings.IsWebMessageEnabled = true;
    
    // Set up message handler
    webView.CoreWebView2.WebMessageReceived += OnWebMessageReceived;
}


### Step 2: Load Station Data
csharp
private void LoadStationData()
{
    string stationDataPath = Path.Combine(
        AppDomain.CurrentDomain.BaseDirectory, 
        "trainData", 
        "stationlist.json"
    );

    if (File.Exists(stationDataPath))
    {
        string jsonContent = File.ReadAllText(stationDataPath);
        var stationData = JsonConvert.DeserializeObject<List<dynamic>>(jsonContent);
        
        allStations = stationData.Select(item => new Station
        {
            name = item.name?.ToString() ?? "",
            code = item.code?.ToString() ?? ""
        }).OrderBy(s => s.name).ToList();
    }
}

### Step 4: Handle Search Button Click
csharp
private async void SearchButton_Click(object sender, RoutedEventArgs e)
{
    // Cancel any ongoing search
    searchCancellationTokenSource?.Cancel();
    searchCancellationTokenSource = new CancellationTokenSource();

    // Validate inputs
    if (string.IsNullOrWhiteSpace(FromStationTextBox?.Text) ||
        string.IsNullOrWhiteSpace(ToStationTextBox?.Text))
    {
        MessageBox.Show("Please enter both stations.");
        return;
    }

    // Update UI
    SearchButton.Content = "Searching...";
    
    try
    {
        // Fetch trains
        List<TrainInfo> trains = await GetTrainDataViaApiAsync(
            FromStationTextBox.Text, 
            ToStationTextBox.Text, 
            searchCancellationTokenSource.Token
        );

        // Display results
        if (trains.Any())
        {
            string htmlTable = CreateTrainTable(trains);
            string completeHtml = CreateStyledHtml(htmlTable, ...);
            webView.CoreWebView2.NavigateToString(completeHtml);
        }
    }
    finally
    {
        SearchButton.Content = "🔍 Get Train Schedule";
    }
}

## API Integration

### Complete API Request Example
csharp
private async Task<List<TrainInfo>> GetTrainDataViaApiAsync(
    string fromStation, 
    string toStation, 
    CancellationToken cancellationToken)
{
    var request = new HttpRequestMessage(HttpMethod.Post,
        $"https://erail.in/rail/getTrains.aspx?Station_From={fromStation}&Station_To={toStation}&DataSource=0&Language=0&Cache=false");

    // Add required headers
    request.Headers.Add("accept", "*/*");
    request.Headers.Add("accept-language", "en-US,en;q=0.9");
    request.Headers.Add("origin", "https://erail.in");
    request.Headers.Add("referer", "https://erail.in/");
    request.Headers.Add("user-agent", "Mozilla/5.0...");

    var response = await httpClient.SendAsync(request, cancellationToken);
    response.EnsureSuccessStatusCode();

    string content = await response.Content.ReadAsStringAsync(cancellationToken);
    return ParseApiResponse(content);
}

private List<TrainInfo> ParseApiResponse(string response)
{
    try
    {
        if (response.Contains("~") && response.Contains("^"))
            return ParsePipeDelimitedData(response);
        else
            return ParseHtmlTable(response);
    }
    catch (Exception ex)
    {
        System.Diagnostics.Debug.WriteLine($"Parse error: {ex.Message}");
        return new List<TrainInfo>();
    }
}

## Performance Optimization Tips

### 1. Async/Await Best Practices
- Use ConfigureAwait(false) for library code
- Avoid blocking calls like .Result or .Wait()
- Properly dispose CancellationTokenSource

### 2. Memory Management
csharp
