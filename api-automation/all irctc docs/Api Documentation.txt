## License & Authentication APIs

### 1. License Validation API

*Endpoint:* https://verifytool.in/api/validate (or similar)

*Method:* POST

*Headers:*

Content-Type: application/json


*Request Payload:*
json
{
  "key": "LICENSE_KEY_HERE",
  "Machine": "DEVICE_ID_HERE"
}


*cURL Command:*
bash
curl -X POST "https://verifytool.in/api/validate" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "LICENSE_KEY_HERE",
    "Machine": "DEVICE_ID_HERE"
  }'


---

### 2. Book Token API

### 4. Validate User / Refresh Token

*Endpoint:* https://www.irctc.co.in/eticketing/protected/mapps1/validateUser?source=3

*Method:* GET

*Headers:*

accept: application/json, text/plain, */*
content-type: application/json; charset=UTF-8
authorization: Bearer ACCESS_TOKEN_HERE
bmiyek: REFRESH_TOKEN_HERE
greq: GREQ_TOKEN_HERE
bmirak: webbm

curl -X GET "https://www.irctc.co.in/eticketing/protected/mapps1/validateUser?source=3" \

## Notes

### Authentication Tokens

All IRCTC APIs require the following authentication tokens:
- *ACCESS_TOKEN*: OAuth Bearer token from IRCTC login
- *REFRESH_TOKEN*: Stored in bmiyek header
- *GREQ_TOKEN*: Stored in greq header
- *CSRF_TOKEN*: CSRF protection token, obtained from response headers
- *SESSION_COOKIES*: Browser session cookies from IRCTC login

### Common Headers

Most IRCTC APIs use these common headers:

accept: application/json, text/plain, */*
content-type: application/json; charset=UTF-8
authorization: Bearer {ACCESS_TOKEN}
bmiyek: {REFRESH_TOKEN}
greq: {GREQ_TOKEN}
bmirak: webbm
X-Requested-With: XMLHttpRequest
spa-csrf-token: {CSRF_TOKEN}


### Payment Flow

1. *Booking Init Payment*: Initialize payment with bank/gateway selection
2. *Payment Redirect*: Redirect to payment gateway (WPS)
3. *Paytm Process*: Process payment through Paytm gateway
4. *UPI Flow* (if applicable):
   - Validate VPA
   - Process Transaction
   - Poll Status
5. *Verify Payment*: Verify payment completion
6. *PNR Status*: Check booking status and get PNR

### Bank IDs

Common bank IDs used:
- *1000*: IRCTC eWallet
- *78*: Paytm (Credit/Debit/NetBanking/UPI)
- *98*: PayU
- *105*: Razorpay
- *116*: PhonePe
- *113*: IRCTC iPay

### Payment Modes

- *1*: Netbanking
- *2*: Cards
- *7*: eWallet
- *9*: IRCTC iPay
- *13*: Gateway (Paytm/PayU/Razorpay/PhonePe)

## Important Security Notes

⚠️ *WARNING*: 
- Never expose authentication tokens in production
- All tokens should be obtained through proper IRCTC login flow
- CSRF tokens are session-specific and time-sensitive
- Payment credentials should never be hardcoded
- Always use HTTPS for all API calls
- Validate all user inputs before sending to APIs
